Task 4.4 - prevent recurrence with @Override

1) In DrawPad.java, TODO 1, change the method name to:

       @Override public void mouseclicked(MouseEvent e) {

2) Compile:   javac DrawPad.java

3) The compiler now stops with this message (record your own output as evidence):

   DrawPad.java:20: error: method does not override or implement a method from a supertype
               @Override public void mouseclicked(MouseEvent e) {
               ^
   1 error

Without @Override the misspelled method is just a NEW method that nobody calls, so the program compiles
and silently does nothing (see DrawPadBroken.java).
